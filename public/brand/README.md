# Brand marks (provider identification)

SVG logomarks used in `LlmModelPicker` to identify the active LLM provider.
These trademarks belong to their respective owners; use here is limited to
identifying DeepSeek / OpenAI models inside the ParisTour UI.

| File | Mark | Source |
|------|------|--------|
| `deepseek.svg` | DeepSeek whale icon | Path matches the whale in [deepseek-ai/DeepSeek-V2 `figures/logo.svg`](https://github.com/deepseek-ai/DeepSeek-V2/blob/main/figures/logo.svg) (official GitHub brand asset). Square icon path via [Simple Icons `deepseek`](https://github.com/simple-icons/simple-icons/blob/develop/icons/deepseek.svg). Brand blue `#4D6BFE`. |
| `openai.svg` | OpenAI blossom logomark | Official OpenAI blossom symbol (see [openai.com/brand](https://openai.com/brand/)). Path via [Simple Icons `openai`](https://cdn.jsdelivr.net/npm/simple-icons@13.21.0/icons/openai.svg), matching OpenAI brand lockup materials. |
| `google.svg` | Google G (four-color) | Google Identity letter mark, used to label Google Places / reviews in place details. |
| `tripadvisor.svg` | Tripadvisor owl | UI source identification. Fill `#00EB5B`. |

Prefer these icon marks over full wordmarks so they stay legible at ~16–20px.
